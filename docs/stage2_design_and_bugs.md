# Этап 2. Проектирование: Карта сайта, User Flow, прототипы и дефекты требований
**Проект:** Веб-сервис каршеринга «MELLDRIVE»
**Команда:** MellSquad

## 1. Карта сайта (Sitemap)
- Главная (/)
- Автопарк / Каталог (/catalog) -> Карточка авто (/car?id=X)
- Поиск (/search)
- Бронирование / Корзина (/cart) -> Оформление (/checkout) -> Спасибо (/thanks)
- Регистрация (/register), Вход (/login), Сброс пароля (/recovery), Личный кабинет (/profile)
- О сервисе (/about), Контакты (/contacts), FAQ (/faq), Политика конфиденциальности (/privacy), 404 (*)
- Админ-панель (/admin/login, /admin/cars, /admin/orders, /admin/users, /admin/reviews, /admin/stats)

## 2. Пользовательские сценарии (User Flow)
- Сценарий 1: Выбор авто -> тариф и опции -> авторизация -> оформление заказа -> появление в ЛК и админке.
- Сценарий 2: Включение режима «Редактор» -> смена названия/логотипа/машин без правки файлов -> сохранение в localStorage / сброс.

## 3. Баг-репорты Этапа 2 (BUG-001..BUG-005)
- BUG-001: Отсутствует проверка минимального возраста и стажа водителя при регистрации.
- BUG-002: Нет защиты от двойного бронирования одного авто на пересекающееся время.
- BUG-003: Клик по логотипу в режиме редактора перекидывал вместо редактирования текста (исправлено).
- BUG-004: В схеме БД не уточнено поведение при удалении категории с активными автомобилями.
- BUG-005: Нужна быстрая кнопка сброса локальных изменений редактора к исходному виду (исправлено).

## 4. Прототипы экранов (Wireframes)
- Главная (/) и Каталог (/catalog): шапка с редактором, hero-блок, фильтры категории/цены, карточки авто, тарифы, FAQ, подвал.
- Карточка авто (/car?id=X) и Оформление (/checkout): фото, характеристики, статус, выбор тарифа/опций, расчёт суммы.
- Личный кабинет (/profile) и Админка (/admin): профиль, статус ВУ, история броней, CRUD автопарка и смена статусов.

## 5. Маршруты (URL / API)
- GET /, GET /catalog, GET /car, GET /search, GET /cart, GET /checkout, GET /login, GET /register, GET /profile, GET /admin
- POST /api/auth/login, POST /api/auth/register, POST /api/bookings, POST /api/admin/cars, PATCH /api/admin/bookings/<id>/status
