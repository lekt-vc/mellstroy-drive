## 3. Шаблон оформления индивидуального баг-репорта

Скопируйте данный блок для создания детального отчета о найденном дефекте:

```markdown
### Баг-репорт BUG-XXX

| Поле | Содержимое |
| :--- | :--- |
| **ID** | BUG-XXX |
| **Заголовок** | [Что сломалось] в [каком модуле/компоненте] при [каких условиях] |
| **Автор** | ФИО (роль) |
| **Исполнитель** | ФИО (роль) |
| **Дата обнаружения** | ДД.ММ.ГГГГ |
| **Модуль / Страница** | URL или название экрана (например, `/checkout`, модальное окно входа) |
| **Окружение** | Браузер (Chrome 130 / Firefox 132), ОС (Windows 11), Разрешение (1920×1080 / 375×812) |
| **Серьёзность (Severity)** | Блокирующий / Критический / Значительный / Незначительный / Тривиальный |
| **Приоритет (Priority)** | Высокий / Средний / Низкий |
| **Предусловия** | Пользователь авторизован, в корзине выбран автомобиль Haval Jolion |
| **Шаги воспроизведения** | 1. Перейти на страницу `/catalog`<br>2. Выбрать фильтр «Электромобили»<br>3. Нажать кнопку «Применить» |
| **Фактический результат** | Отображается пустой экран без сообщения «Ничего не найдено», в консоли ошибка Uncaught TypeError |
| **Ожидаемый результат** | Отображается список доступных электрокаров либо информационная плашка «Автомобили данной категории временно отсутствуют» |
| **Вложения** | Скриншот `docs/bugs/BUG-XXX_screen.png`, лог консоли |
| **Статус** | Новый / Назначен / В работе / Исправлен / На перепроверке / Закрыт |
| **Описание исправления** | Что было исправлено в коде, ссылка на коммит (например, `fix: BUG-XXX обработка пустого массива авто (коммит 4f1a2c3)`) |
| **Перепроверка** | Кто перепроверил (ФИО), дата, результат проверки («Исправлено, дефект не воспроизводится») |
```

## 4. Шкала серьёзности (Severity)
- **Блокирующий (Blocker):** Полная неработоспособность ключевого функционала (невозможно зарегистрироваться, крах сервера, белый экран).
- **Критический (Critical):** Нарушение бизнес-логики без обходного пути (деньги списываются неверно, пароли в открытом виде в БД, XSS/SQLi).
- **Значительный (Major):** Функция работает некорректно, но есть обходной путь (фильтр по цене не сбрасывается).
- **Незначительный (Minor):** Визуальные дефекты верстки, расхождения с макетом Figma, мелкие отступы.
- **Тривиальный (Trivial):** Опечатки в текстах, неточности в описании тарифов.
