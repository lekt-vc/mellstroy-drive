# Тест-кейсы сервиса каршеринга «MELLDRIVE»
**Команда:** MellSquad  
**Требования:** не менее 20 тест-кейсов (включая не менее 6 негативных).

---

| ID | Название тест-кейса | Модуль | Тип теста | Прогон 1 | Прогон 2 | Регрессия |
| :--- | :--- | :--- | :--- | :---: | :---: | :---: |
| **TC-001** | Успешная регистрация нового водителя с валидными данными | Регистрация | Позитивный | П | П | П |

| **TC-003** | Регистрация со стажем вождения менее 1 года | Регистрация | Негативный | Н (BUG-001) | П | П |

## 2. Шаблон описания тест-кейса

```markdown
### Тест-кейс TC-XXX

| Поле | Описание |
| :--- | :--- |
| **ID** | TC-XXX |
| **Название** | Краткое название сценария проверки |
| **Модуль** | Регистрация / Каталог / Бронирование / Личный кабинет / Админка |
| **Тип** | Позитивный / Негативный; Функциональный / UI / Безопасность |
| **Предусловия** | База данных наполнена тестовыми автомобилями, пользователь авторизован |
| **Шаги проверки** | 1. Открыть страницу URL...<br>2. Заполнить поле X значением Y...<br>3. Нажать кнопку «Подтвердить» |
| **Ожидаемый результат** | Система отображает сообщение об успехе, создается запись в таблице orders |
| **Фактический результат** | Соответствует ожидаемому / Ошибка (номер бага BUG-XXX) |
| **Статус** | Пройден (Pass) / Провален (Fail) / Заблокирован (Blocked) |
```
