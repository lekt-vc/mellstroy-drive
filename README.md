##  О проекте

**«MELLDRIVE»** — это сервис поминутной, часовой и суточной аренды легковых автомобилей. Веб-платформа позволяет пользователям ознакомиться с автопарком, выбрать подходящий автомобиль по фильтрам (класс, трансмиссия, тип двигателя), забронировать его, управлять поездками в личном кабинете, а администраторам — централизованно управлять парком, тарифами, статусами заказов и клиентской базой.

##  Технологический стек

- **Дизайн и прототипирование:** Figma (UI-kit, компоненты, Wireframes, Mobile/Tablet/Desktop макеты).
- **Фронтенд:**
  - HTML5 (семантическая верстка, доступность ARIA);
  - CSS3 / SCSS (Flexbox, CSS Grid, CSS-переменные для темной/светлой темы);
  - Чистый JavaScript (ES6+), асинхронные запросы (Fetch API);
  - Адаптив: 320 px, 375 px, 768 px, 1024 px, 1440 px, 1920 px.
- **Бэкенд:**
  - Серверная среда: Node.js (Express) / Python (Flask) / PHP (PDO);
  - База данных: Реляционная СУБД (MySQL / SQLite / PostgreSQL);
  - Безопасность: Хеширование паролей (`bcrypt`), защита от SQL-инъекций (Prepared Statements), защита от XSS и CSRF, ограничение прав по ролям.
- **Инструменты контроля качества (QA) и тестирования:**
  - Google Chrome DevTools, Lighthouse (Performance ≥ 70, Accessibility ≥ 80);
  - W3C Markup Validation Service, Postman (тестирование маршрутов API);
  - Набор из 20+ тест-кейсов (TC-xxx) и сводный журнал дефектов (BUG-xxx).
- **Система контроля версий:** Git (GitHub / GitLab).

##  Инструкция по запуску и разработке

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd MellDrive
```

### 2. Запуск фронтенда (локально)
Для просмотра статической верстки достаточно открыть `frontend/index.html` в браузере или использовать расширение **Live Server** для VS Code / встроенный сервер:
```bash
# Пример запуска через простой локальный сервер:
npx serve frontend
# или (Python):
python -m http.server 3000 --directory frontend
```

### 3. Настройка базы данных
Импортируйте структуру и тестовые данные в вашу СУБД:
```bash
# Для MySQL:
mysql -u root -p melldrive < backend/database/schema.sql
mysql -u root -p melldrive < backend/database/seeds.sql
```
