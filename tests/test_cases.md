# Тест-кейсы проекта «MELLDRIVE» (TC-001..TC-020)
**Команда:** MellSquad

| ID | Сценарий | Предусловие | Шаги проверки | Ожидаемый результат |
| :--- | :--- | :--- | :--- | :--- |
| **TC-001** | Фильтрация каталога по классу | Открыт `catalog.html` | Выбрать класс «Спорт» | Отображаются только авто класса «Спорт» |
| **TC-002** | Поиск автомобиля по марке | Открыт `catalog.html` | Ввести «Tesla» в строку поиска | В списке остаётся Tesla Model 3 |
| **TC-003** | Сортировка по цене по возрастанию | Открыт `catalog.html` | Выбрать «Цена: сначала дешевле» | Карточки сортируются от минимальной цены/сутки |
| **TC-004** | Сброс фильтров каталога | Применён фильтр и поиск | Нажать «Сбросить фильтры» | Показаны все авто, поля очищены |
| **TC-005** | Расчёт тарифа «Минуты» | Открыт `car.html?id=1` | Выбрать «Минуты (30 мин)» | Итог равен `priceMin * 30` |
| **TC-006** | Расчёт тарифа «Сутки» | Открыт `car.html?id=4` | Выбрать «Сутки (24 ч)» | Итог равен суточной стоимости авто |
| **TC-007** | Добавление опции КАСКО | Открыт `car.html?id=1` | Отметить чекбокс КАСКО | Итоговая сумма увеличивается на 490 ₽ |
| **TC-008** | Оформление брони и запись в ЛК | Выбран тариф на `car.html` | Нажать «Оформить бронирование» и открыть `profile.html` | Бронь `MD-...` появилась в таблице ЛК со статусом «Активна» |
| **TC-009** | Завершение активной поездки в ЛК | Есть активная бронь в `profile.html` | Нажать «Завершить» напротив заказа | Статус меняется на «Завершена» |
| **TC-010** | Очистка истории поездок в ЛК | Открыт `profile.html` | Нажать «Очистить историю» | Таблица показывает пустое состояние |
| **TC-011** | Регистрация пользователя >= 18 лет | Открыт `register.html` | Указать дату рождения > 18 лет и отправить | Переход в `profile.html` без ошибок |
| **TC-012** | Негативный тест: регистрация < 18 лет | Открыт `register.html` | Указать дату рождения младше 18 лет и отправить | Выводится сообщение об ограничении возраста |
| **TC-013** | Переход в UI-кит | Открыт `index.html` или `catalog.html` | Перейти на `ui-kit.html` | Отображаются палитра, кнопки и поля ввода |
| **TC-014** | Открытие несуществующего маршрута | Перейти на `404.html` | Открыть страницу 404 | Отображается экран 404 и кнопки возврата |
| **TC-015** | Синхронизация авто из редактора | Добавлено авто в редакторе на главной | Открыть `catalog.html` | Новое авто отображается в каталоге |
| **TC-016** | GET /api/cars возвращает автопарк | Запущен `backend/api_server.py` | Запросить `GET /api/cars` | Ответ 200 и JSON со списком машин |
| **TC-017** | POST /api/bookings создаёт бронь | Запущен `backend/api_server.py` | Отправить `POST /api/bookings` с `{"car_id": 1}` | Ответ 201 и созданная бронь |
| **TC-018** | Негативный тест: несуществующее авто в API | Запущен `backend/api_server.py` | Отправить `POST /api/bookings` с `{"car_id": 999}` | Ответ 404 с сообщением об ошибке |
| **TC-019** | Негативный тест: битый JSON в POST | Запущен `backend/api_server.py` | Отправить некорректный JSON на `/api/bookings` | Ответ 400 `Invalid JSON` |
| **TC-020** | Адаптивность на мобильном экране | Открыть `catalog.html` на 375 px | Проверить сетку карточек и тулбар | Элементы перестраиваются в одну колонку без горизонтального скролла |
